# VisualSwap Playground

Trang demo phát lại thí nghiệm VisualSwap (đổi ảnh giữa lúc model đang suy luận) trên 4 model thị giác–ngôn ngữ
(Ministral-3 8B Reasoning/Instruct, Qwen3-VL 8B Thinking, Qwen3-VL 4B Instruct) với 8 cặp ảnh từ VS-Bench.

Mọi lời giải, đáp án và số liệu attention được ghi lại từ lần chạy thật các model (NF4 4-bit, GPU RTX 5060 Ti);
trang chỉ phát lại dữ liệu đã lưu. Toàn bộ nằm trong một file `index.html`, mở trực tiếp bằng trình duyệt.
